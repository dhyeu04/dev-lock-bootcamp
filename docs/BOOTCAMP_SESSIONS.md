# Bootcamp Sessions

The list below mirrors the 7 rows in the `Bootcamp` tab.

## Session 01 - Blockchain Fundamentals

Topics:

- What is Blockchain?
- Centralized vs Decentralized
- Why Bitcoin was created
- How Ethereum extends blockchain use cases
- Blockchain benefits and use cases

Expected evidence: a concise concept summary plus one real-world use case.

## Session 02 - How Blockchain Works

Topics:

- Block and blockchain structure
- What a transaction is
- Ledger and state
- Nodes and P2P network
- Transaction lifecycle
- Blockchain explorer

Expected evidence: a transaction lifecycle walkthrough and an explorer link or
annotated screenshot.

## Session 03 - Cryptography & Wallet

Topics:

- Hashing
- Public key and private key
- Digital signature
- Wallet and address
- Seed phrase
- Custodial vs non-custodial wallet
- Basic wallet security

Expected evidence: a safe testnet wallet walkthrough. Never include a seed phrase
or private key.

## Session 04 - Consensus & Blockchain Architecture

Topics:

- What consensus means
- Proof of Work and Proof of Stake
- Finality
- Layer 1 and Layer 2
- Account-based vs UTXO
- Public, private, and permissioned blockchain

Expected evidence: a comparison table and an architecture diagram or source link.

## Session 05 - Smart Contracts & Digital Assets

Topics:

- Smart contracts
- Native coin vs token
- Mint and burn
- Stablecoins
- NFTs
- Gas and transaction fees
- Intro to EVM, SVM, and WASM

Expected evidence: one asset or smart-contract concept explained with a
verifiable source or testnet result.

## Session 06 - DApps & Web3 Ecosystem

Topics:

- dApp architecture
- Frontend to wallet to smart contract to blockchain
- DeFi
- Payments
- NFTs
- Gaming
- DAO
- Intro to oracles
- Mini demo on testnet

Expected evidence: a simple dApp flow diagram and a testnet demo link or
screen recording/screenshot.

## Session 07 - Practice + AMA

Practice:

- Create a testnet wallet
- Receive faucet tokens
- Send a transaction
- View the transaction on an explorer
- Connect the wallet to a simple dApp
- Recap, Q&A, and Phase 2 introduction

Expected evidence: wallet address, transaction hash, explorer URL, and dApp
connection proof. Do not expose credentials.
