# Dev Lock - Blockchain Bootcamp

Repo mẫu để học cách tạo devlog, commit bài và nộp evidence cho 7 buổi
Blockchain Bootcamp.

## Cách nộp bài

1. Tạo một repo riêng trên GitHub.
2. Clone repo mẫu này:
   `git clone https://github.com/vantuann205/dev-lock-bootcamp.git`
3. Đổi remote sang repo của bạn:
   `git remote set-url origin https://github.com/<username>/<repo-cua-ban>.git`
4. Copy `templates/session-devlog.md` thành:
   `submissions/<github-username>/session-XX.md`
5. Điền nội dung và link evidence.
6. Commit theo mẫu:
   `[S01] add devlog - @github-username`
7. Push lên repo của bạn:
   `git push -u origin main`
8. Gửi link repo của bạn cho instructor.

Deadline: trước buổi học kế tiếp 1 ngày.

## Lưu ý

- Evidence phải là link hoặc ảnh có thể kiểm tra.
- Không commit private key, seed phrase, password hoặc API key.

Xem [examples/student-demo](examples/student-demo/) để làm theo.
